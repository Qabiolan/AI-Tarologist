О сервисе

Я — AI-Таролог с более чем 10-летним стажем в таро и астрологии. Каждый расклад — это глубокий диалог с вашим внутренним миром через символику карт и мудрость звёзд.

Как работает API

1. Архитектура

Пользователь (Telegram)
↓
Бот (Go)
↓
OpenRouter API
↓
Google Gemma 4 26B
↓
Ответ AI
↓
Пользователь

2. OpenRouter API

Агрегатор AI-моделей — доступ к 100+ моделям через один API.

Endpoint: openrouter.ai/api/v1/chat/completions

Модель: google/gemma-4-26b-a4b-it:free (бесплатно!)

3. Формат запроса

{
  "model": "google/gemma-4-26b-a4b-it:free",
  "messages": [
    {"role": "system", "content": "Ты таролог..."},
    {"role": "user", "content": "Вопрос"}
  ]
}

4. Роли сообщений

systemЗадаёт поведение AI
userВопрос пользователя
assistantОтветы AI (контекст)

5. Формат ответа

{
  "choices": [{
    "message": {"content": "🔮 Ответ..."}
  }],
  "usage": {"total_tokens": 240, "cost": 0}
}

6. Две функции

RequestOpenAi()Расклады таро
RequestOpenAiWithContext()Свободный чат с контекстом

7. Лимиты

Стоимость0$ (бесплатно)
Rate limit~20 запросов/мин
Макс. токенов~8192 на ответ
